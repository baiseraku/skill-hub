# R 代码要求：精简注释 + 落盘脚本

本会话产出的任何 R 代码都执行两条硬性要求：

- 代码必须写入项目 .R 脚本并持续更新，禁止只在对话里贴代码
- 注释只讲必要信息，且按固定风格书写

## 落盘要求：代码进 .R 脚本

- 新增/修改的 R 代码一律保存进工作目录的 .R 脚本（沿用现有 QC.R / ANL.R 等，或为独立分析新建脚本），保存后再运行
- 分析分步推进时，每完成一步就把代码更新进脚本并运行，保证脚本内容始终等于当前已执行的全部分析
- ⚠️ 例外：仅把模板/现有流程适配到新数据（换参数、补注释、拼脚本）时，允许只把代码写入
  .R 脚本而不运行——运行与否由用户决定；交付时注明“未运行”
- 路径、阈值、样本名等参数写在对应的读入/导出代码旁并随脚本保存，不依赖对话记忆补参数
- 路径直接以字面量写在调用处，不为设置路径单独建变量（同一路径确实多处重复时才提局部变量）；阈值等可调参数就近用带名变量定义
- 禁止把参数集中堆在文件顶部当“参数区 / 环境变量”
- 修改已有脚本前先通读该文件，沿用其分节与命名习惯，只做增量修改，不整体重排

## 注释要求：只讲必要信息

- 注释只写代码本身读不出的内容：为什么这样做、边界与坑、输入输出约定、⚠️ 必改项
- 代码自明处不写注释（函数名、参数含义、显而易见的赋值都不复述）
- 禁解释性废话：不复述代码行为、不写流水账、不写“本步骤将……”
- 阶段级“输入 / 输出”清单只在会被独立运行、跨脚本引用的位置写；整链顺序执行、对象一路沿用时可省

## 注释风格

- 短分节：`# 标题 ----`（标题 = 这段在干什么；结尾 4 个以上 `-`）
  - `----` 只留给阶段级分节（`# 阶段 A：加载对象，输出最初 QC 小提琴图 ----`）和少数大块标题；阶段内部的细粒度小节只写 `# 简短标题`，不挂 `----`
- 冒号对齐清单：同组注释用“标签：值”逐行对齐，标签说明字段，值给具体内容
  - 输入输出、样本清单、⚠️ 必改项等都写成对齐清单
- 行内说明：只给容易误读、有坑、有取舍的代码行加行尾 `# 短说明`，说明“为什么”而非“是什么”
  - `⚠️` 只挂真正会报错、或必须人工核对的位置（线粒体前缀、`cc.genes` 物种、`cell_type_map`）；一般可调参数不逐条挂 `⚠️`，一句“可按需调整”带过；最关键处用 `⚠️⚠️ 必改：`
  - 控制台分节用 `cat("\n==== 标题 ====\n"); print(...)`：那是运行输出分隔，不属于被禁的注释装饰框
- 禁止项
  - 装饰框：整行 `=====` / `-----` 横幅、`# *****`、盒子画线等（`----` 只作为分节标题结尾）
  - 序号：不用“1. 2. 3.”或“首先/其次/然后”的编号式铺陈
  - 解释性废话：见“注释要求”

## 示例

照此写：

```r
setwd("/Volumes/Tiplus/R/Project/260903-1")

# 阶段 A：加载对象，输出最初 QC 小提琴图 ----
# 输入：output/import.rds（前序合并对象，须含 sample 列）
seurat <- readRDS("output/import.rds")
# Seurat v5 访问不存在的列会直接报错（v4 才返回 NULL），故不用 is.null 探测
if (!"sample" %in% colnames(seurat@meta.data)) seurat$sample <- seurat$orig.ident

# QC 指标
seurat$nCount_RNA   <- Matrix::colSums(cnts)
seurat$nFeature_RNA <- Matrix::colSums(cnts > 0)
# 物种线粒体前缀：人类 ^MT- / 小鼠 ^mt-
seurat[["percent.mt"]] <- PercentageFeatureSet(seurat, pattern = "^MT-")
```

禁止这样写：

```r
# =============================================
# 阶段 A：加载合并对象并输出初始 QC 小提琴图
# 1. 首先用 readRDS() 读取已合并的对象
# 2. 接着用 PercentageFeatureSet() 计算线粒体比例
# 3. 最后用 VlnPlot() 画图并保存为 PDF
# =============================================
seurat <- readRDS("output/seurat_merged.rds")   # 读取对象文件
seurat[["percent.mt"]] <- PercentageFeatureSet(seurat, pattern = "^MT-")
```

## 完成后自查

- 本次产出的 R 代码都已更新进 .R 脚本；实际运行过的分析脚本与结果一致，仅适配未运行的注明“未运行”
- 脚本没有文件顶部集中“参数区 / 环境变量”，也没有为单个路径建的无谓变量；路径以字面量出现在读入/导出调用处，阈值就近以带名变量定义
- `----` 只出现在阶段级分节标题上，阶段内部的小节是普通 `# 标题`
- `⚠️` 没有泛滥：只出现在会报错或必须人工核对的位置，最关键的用 `⚠️⚠️ 必改：`
- 注释里没有装饰框、没有“1. 2. 3.”式序号、没有解释性废话
- 每条注释都能回答“为什么”或提供代码本身读不出的信息
